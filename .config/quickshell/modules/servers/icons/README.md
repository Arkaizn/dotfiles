# Server logos

Brand icons from [Simple Icons](https://simpleicons.org) (CC0 1.0), each filled with its
brand colour (very dark ones in light grey, for dark themes). The names and logos are
trademarks of their owners; they are used here only to label the servers that run them.

Add one: put `<name>.svg` here and add `<name>` to `ServerStore.logos`.
